## 2. 段階的実装ロードマップ（今後の開発予定）

### Phase 1: シーン・複数体配置基盤 (基礎)
- [ ] シーンデータ構造 (`SceneData`, `SceneActorPlacement`) の設計
- [ ] 複数体同時スポーン・個別デスポーン管理 (`SceneManager`)
- [ ] 座標（X, Y, Z）・回転（Rotation）・テリトリーIDの保存と復元
- [ ] UI: シーン一覧・作成・編集・一括スポーン/デスポーン画面

### Phase 2: モーション・視線・表情・接近リアクション制御
- [ ] `AnimationService`: `ActionTimeline` によるモーション再生・無限ループ制御
- [ ] 表情（Facial）スロット固定制御
- [ ] 視線追従（LookAt / Head Tracking）制御（自キャラ追従 / 固定）
- [ ] 接近トリガー（Proximity Reaction）エンジン（待機モーション ⇔ 接近リアクションの自動遷移）

### Phase 3: ネームプレート・称号制御
- [ ] `NamePlateService`: Dalamud 公式 `INamePlateGui` イベントフック実装
- [ ] パペット単位のネームプレート表示／非表示切り替え
- [ ] 称号（Title）の表示／非表示およびカスタム称号付与

### Phase 4: サウンド制御 (将来拡張)
- [ ] `SoundService`: 3D空間オーディオエンジン（距離計算と音量減衰）
- [ ] パペットへのサウンド登録と接近トリガー再生

### Phase 5: アセットハイダー (将来拡張)
- [ ] `AssetHiderService`: カメラ・カーソルによるマップ配置オブジェクトのスポイト選択
- [ ] 既存オブジェクトの `DisableDraw()` による一時消去およびシーン保存・復元
