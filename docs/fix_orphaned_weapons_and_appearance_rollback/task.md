# タスク: 武器の地面残存バグと異種族・男性キャラの外見ロールバック問題の根本解決

## 現状の課題
1. **武器だけがマップ上に残る現象 (Orphaned Weapon Bug)**:
   - スポーンとデスポーンを繰り返すと、地面にマンダヴィル・ガンブレード等の武器モデルが突き刺さったまま孤立して残る。
2. **男性キャラ（Chonk 等）をスポーンしても自キャラ（女性ミコッテ）のまま描画される現象**:
   - Glamourer のデザイン適用ログは成功しているにもかかわらず、画面上では女性ミコッテ（自キャラの素体）のまま描画されてしまう。
3. **前キャラの情報が残留・混ざり合ってしまう現象**:
   - スポーン・デスポーンを繰り返すと直前のステート（LyleやChonk）が混ざったり、削除したはずのデータの影響を受ける。

## 完了基準
- [x] デスポーン時に武器モデルがワールド上に取り残されないこと。
- [x] 男性キャラ（ハイランダー等）や異種族・異性別のキャラクターをスポーンした際、自キャラの姿に巻き戻らず正しい外見で描画されること。
- [x] スポーン ⇔ デスポーンを繰り返しても前回の外見情報が残留しないこと。
- [x] v0.1.32.0 のビルド＆プッシュ完了。
