# 修正内容の確認 (Walkthrough): 開発記録完全アーカイブ ＆ 次期セッション引き継ぎ仕様

## 1. 直近開発スプリントの完全記録（v0.1.71.0 〜 v0.1.92.0）

### ① アクション・モーション再生基盤 ＆ 表情固定 ＆ 視線追従 (v0.1.71.0 〜 v0.1.81.0)
- **ネイティブモーション制御パイプライン**:
  - HDM 準拠の ActionTimeline 再生、ループ再生、速度変更（0.1x〜3.0x）を実装。
- **表情固定（Facial Expression Freezing）**:
  - 表情専用スロット（スロット2）へ表情タイムラインを再生し、Brio DFC 準拠で速度を `0.0f` にフリーズ。待機・移動モーションを維持したまま表情だけを永続固定。
- **視線・体幹追従（LookAt Player & LookAt Custom Spawn）**:
  - 自キャラ注視だけでなく、同一シーン内の別カスタムスポーン（Puppet）への相互注視を実現。
  - Puppet にクライアント専用の探索可能 `EntityId` と `TargetableStatus` を付与し、ゲームエンジンの LookAtIK システムに完全認識させることに成功。
  - 体幹回転角制限（`BodyTurnAngleLimit`: 首・視線のみ〜45度〜180度）、有効距離スライダー（デフォルト 15m）、超過警告と自動調整（Fit）ボタンを実装。
- **デミヒューマン（DemiHuman, Type 2）描画の完全解決**:
  - サキュバス・スケルトン等の一体型モデルが透明になる問題を SqPack バイナリ解析によって特定。
  - 胴（Body）スロットのみにモデルIDを適用し、他スロットをゼロクリアすることで 100% 安定描画を達成。
- **モーションお気に入り機能**:
  - 星マーク（★/☆）によるワンクリック登録、永続保存、最優先ソート、および `Favorite` カテゴリを新設。

### ② 自律移動AI ＆ ウェイポイント巡回 ＆ 追従・帰還ステートマシン (v0.1.82.0 〜 v0.1.84.0)
- **自律移動エンジン（NavigationService）**:
  - 毎フレームのステートマシン（Idle, Patrol, Follow, ReturnHome）。
  - ウェイポイント巡回（Loop / PingPong / Once）、速度選択（Walk 2m/s, Run 4m/s）。
  - 目標地点への滑らかな回転（Slerp）と移動アニメーション（Walk / Run）の自動適用。
- **プレイヤー接近追従 ＆ ホームポジション帰還**:
  - Trigger Distance（接近検知）で歩み寄り開始、Stop Distance（停止距離）で停止。
  - Leash Range（離脱距離）超過で自動的に初期配置位置（Home Position）へ帰還。
- **3D ギズモ範囲可視化**:
  - 巡回パス（3D線・地点球体）、Trigger Dist（青円）、Stop Dist（緑円）、Turn Angle（黄色扇形）のオーバーレイ表示。Show Ranges トグルで非表示可能。
  - 移動方向ジッターのデッドゾーン導入による解消。

### ③ 自キャラ抜刀時の武器リーク防止 ＆ 0xC0000005クラッシュ完全根絶 (v0.1.85.0 〜 v0.1.87.0)
- **事象**:
  - 自キャラが武器を抜刀した状態でShowを行うと、モンスターやデミヒューマン（サキュバス）、NPC（アリゼー等）がプレイヤーと全く同一の武器を手に持ってしまう。
  - 最初に対処した際、`WeaponData` 構造体をゼロクリアしたことでメモリ境界破壊が発生し、Access Violation (0xC0000005) でゲームが強制終了した。
- **原因と解決**:
  - COM アクター（Puppet）は自キャラをベースラインとしてメモリ複製（`CloneActor`）されるため、自キャラの抜刀状態フラグや武器モデルIDがコピーされていた。
  - ネイティブの安全な API `chara->IsWeaponHidden = true` を採用し、本来武器を持たないモンスター・デミヒューマンは非表示を強制。
  - NPC（アリゼー等）や元から武器を持つモンスター（トールダン等）に対しては、NPC 外見データ（`NpcEquip` / `CustomSpawnPlacement`）から本来の武器モデルIDを安全に再ロードして維持。自キャラの武器が乗り移る現象とクラッシュを完全根絶。

### ④ 階段・段差の自動適応（地形レイキャスト）(v0.1.88.0)
- **事象**:
  - 巡回ルートを指定した際、階段や傾斜・段差があるとキャラクターが地面にめり込んでしまい、不自然になる。
- **解決**:
  - FFXIV ネイティブのコライダー衝突判定システム `BGCollision`（`RaycastDown`）を `NavigationService` に統合。
  - キャラクターの現在位置から鉛直下向きに地形レイキャストを行い、衝突した地形サーフェスの Y 座標を取得して垂直スナッピング（Lerp 補間）。
  - ウェイポイントを階段の段数分細かく登録しなくても、自動的に階段や坂道を綺麗に上り下りして巡回するようになった。

### ⑤ 3Dモデル直接クリック選択 ＆ 追従停止時ジッター解消 (v0.1.89.0 〜 v0.1.90.0)
- **事象**:
  - スポーン数が増えるにつれて、SceneEditWindow のカスタムスポーン一覧から対象を探して選択するのが煩雑。
  - 特定の場所で追従してきたカスタムスポーンが停止した際、上下に激しく振動（ジッター）する。
  - モンスター・デミヒューマン・マウント・ミニオンをクリックしても選択されない。
- **解決**:
  - 画面上の 3D モデルを直接左クリックして選択アクターを切り替える機能を実装。
  - ゲーム内ターゲットシステム（`TargetSystem->Target`）の監視と、カメラ投影（`WorldToScreen`）による画面空間距離判定の 2 系統アプローチを採用。
  - 全モデル種別（人型・モンスター・デミヒューマン・マウント・ミニオン）に有効な `EntityId` と `IsTargetable` フラグを付与し、全種別で直接クリック選択が可能に。
  - 追従停止時の上下振動は、停止ステートでの独自 Y 座標補正を撤廃し、高度制御を `BGCollision` レイキャストに一元化したことで完全に消滅。

### ⑥ ネームプレート表示ルール ＆ ターゲット可否分離 (v0.1.91.0 〜 v0.1.92.0)
- **事象**:
  - 全アクターの頭上にネームプレートが出てしまい景観を損ねる。Edit を開いているときだけ表示し、通常時は `[x] Custom Name` を有効にしているアクターだけ表示したい。
  - また、Edit を開いていない通常時はカスタムネーム表示中以外のアクターをターゲットできないようにしたい（一般モブ等の誤選択防止）。
- **解決**:
  - `SceneEditWindow.IsOpen` を `NamePlateService` および `ActorManager` と連携。
  - Edit 開示時: 全アクターのネームプレートを表示し、全アクターをターゲット可能（直接クリック選択をサポート）。
  - Edit 非表示（通常時）: `[x] Custom Name` が有効なアクターのみネームプレートを表示し、そのアクターのみゲーム内でターゲット可能。その他のアクターは `IsTargetable = false` に設定してターゲットから完全除外。
  - 新規カスタムスポーン作成時は `Custom Name` の初期値をチェック OFF（非表示）に設定。
