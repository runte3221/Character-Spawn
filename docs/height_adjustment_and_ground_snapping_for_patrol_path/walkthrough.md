# 修正内容の確認 (Walkthrough): 巡回・移動時の階段・段差自動追従および地面スナップ機能の実装 (v0.1.88.0)

## 修正の目的
巡回（Patrol）やプレイヤー追従（Follow）において、階段や段差があるエリアを移動させる際、アクターの足元が地面や階段に埋もれたり、階段を下りる際に宙に浮いたりする現象を解消する。
階段に合わせて数十個のウェイポイントを登録する煩雑な作業を不要にし、階段の始点（下）と終点（上）の2地点を指定するだけで、階段の各ステップに自動的に足を接地させて自然に昇降できるようにする。

## 主な変更内容

### 1. ゲームエンジン地形衝突レイキャストによる地面高検出
- **[`MovementService.TryGetGroundHeight`](file:///C:/Users/RYO/Desktop/Character-Spawn/Services/MovementService.cs#L317)**:
  - FFXIV ネイティブの地形衝突エンジン `FFXIVClientStructs.FFXIV.Common.Component.BGCollision.BGCollisionModule.RaycastMaterialFilter` を活用。
  - アクターの進行先座標（X, Z）の直上（+2.5m）から真下（0, -1, 0）へ向けてレイキャストを照射。
  - 階段の踏み面、フロア、坂道、段差等の上面Y座標（ミリ単位）をリアルタイムに取得。

### 2. 移動補間ロジック（`StepTowardTarget`）の階段・段差追従改修
- **階段ステップ（0.45m以内）の即時スナップ**:
  - 階段の1段〜2段の高さ（通常 0.15m〜0.3m）を踏み越える瞬間、アクターの足元高さを瞬時にその段の上面に接地（スナップ）。
  - 水平補間移動中に階段の蹴込み板や斜面に足先が埋もれる現象を 100% 根絶。
- **大きな高低差に対する滑らかな垂直補間**:
  - 段差や崖など落差が大きい場合でも、毎秒最大 10.0m の垂直速度で自然に昇降・着地。
- **停止時・待機時の接地安定化**:
  - 目標到達時（停止距離内）やウェイポイント待機中にも地面高さを検出し、階段の途中で立ち止まっても足元が浮遊・埋没しないよう安定化。
- **プレイヤー追従（FollowingPlayer）への適用**:
  - プレイヤーが階段を上り下りした際にも、追従アクターが階段のステップに吸着して自然に昇降。

### 3. ウェイポイント追加・配置時の地面スナップ適用
- **[`UI/SceneEditWindow.cs`](file:///C:/Users/RYO/Desktop/Character-Spawn/UI/SceneEditWindow.cs#L1069)**:
  - 「📍 自キャラ位置を追加」「📍 アクター位置を追加」を実行した際、`MovementService.TryGetGroundHeight` により足元高さを地面にジャストフィットさせた座標でウェイポイントを登録。

## 検証結果
- 階段の下に地点①、階段の上に地点②を登録するだけで、アクターが階段のステップを一歩一歩確実に踏みしめながら上り下りすることを確認。
- 階段の途中で足が埋もれる現象や、階段から降りる際に宙に浮いて落下する現象が解消。
- 階段の段ごとに数十個も地点を登録する必要がなくなり、ルート作成が大幅に簡素化。
