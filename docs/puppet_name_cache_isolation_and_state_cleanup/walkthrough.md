# ウォークスルー: パペット名キャッシュ分離と完全ステートリセット (v0.1.30)

## 修正の確認

### 1. アクター名の決定論的一意化
- [x] キャラクターごとに `Csp {template.Id:N8}` という一意の名前が命名されるよう変更。
- [x] スポーン⇒デスポーン⇒再スポーンを何度繰り返しても、他のキャラ（ChonkやLyle等）の名前と衝突しないため、Glamourer/Penumbraの内部キャッシュによる他キャラ外見の混入が防止されます。

### 2. Glamourer / Penumbra / CustomizePlus の完全リセット
- [x] デスポーン時に Glamourer のステートロック解除とリバート、Penumbra コレクション解除、CustomizePlus の一時プロファイル削除を確実に実行。
- [x] 新しい外見適用前にもアクターのスロットを完全にクリーンアップ。

### 3. 設定ファイル内の不要なプロファイル削除
- [x] `Ruma` テンプレートに誤って保存されていた Chonk（体型・骨格）プロファイル情報を削除し、本来の女性キャラクターのデザインがそのまま反映されるよう修正。

## ユーザー動作確認手順
1. ゲーム内でプラグインリストから **Character Spawn** を最新版（**v0.1.30**）に更新するか、プラグインを再読み込みしてください。
2. キャラクターライブラリから `Ruma` を選択し、**Spawn** をクリックします。
   - `Ruma` の正しい外見でスポーンすることを確認します。
3. **Despawn** をクリックし、再度 **Spawn** をクリックします。
   - 何度繰り返しても、Lyle や Chonk の見た目に化けることなく、常に `Ruma` の正しい姿でスポーンすることを確認します。
4. 他のキャラクターをスポーン・デスポーンしても、以前のキャラクターの見た目やコレクションが引きずられないことを確認します。
