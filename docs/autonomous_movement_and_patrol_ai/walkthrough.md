# 修正内容の確認 (Walkthrough): 自律移動 AI ＆ パトロール・追従・復帰ルーチン統合

## 概要
本ドキュメントは、Character Spawn における **【Step 2.2】自律移動 AI ＆ パトロール・追従・復帰ルーチン** の実装内容と動作確認手順を記録します。

---

## 実装内容詳細

### 1. データモデルの拡張 (`Models/SceneData.cs`)
既存のシーンデータ（`scenes.json`）との 100% 後方互換性を保持しながら、各配置アクター（`SceneActorPlacement`）に `Movement` 設定を追加しました。
- `MovementMode`:
  - `None`: 静止（従来通りの定点配置）
  - `Patrol`: ウェイポイント巡回
  - `FollowPlayer`: プレイヤー接近時の歩み寄り・追従
  - `PatrolAndFollow`: 通常は巡回し、プレイヤーが近づいたら一時中断して追従
- `PatrolLoopType`:
  - `Loop`: 循環巡回（A → B → C → A ...）
  - `PingPong`: 往復巡回（A → B → C → B → A ...）
  - `Once`: 片道巡回（A → B → C 到着で終了）
- `SceneActorWaypoint`:
  - 各地点の 3D 座標（`Position`）、到着時の待機秒数（`WaitSeconds`）、到着時モーション再生（`ActionTimelineId`）、メモ
- `SceneActorMovementConfig`:
  - 移動速度（`Speed`）、旋回速度（`TurnSpeed`）、接近検知距離（`FollowTriggerDistance`）、停止距離（`FollowStopDistance`）、テリトリー限界距離（`MaxTerritoryDistance`）、ホーム帰還フラグ（`ReturnToHome`）

### 2. 自律移動エンジン基盤 (`Services/MovementService.cs`)
- `IFramework.Update` による高精度かつ安全なフレーム更新ループ。
- 目標地点への滑らかな旋回（Yaw角補間）と、速度 × デルタタイムによる前進移動。
- フレームレート急低下時（ラグ）の巨大ワープを防ぐデルタタイムクリップ（最大 0.1秒）。
- `ActorManager.UpdateActorTransform` を介してゲーム内の Puppet（COM スロット）へリアルタイムに座標を反映。
- ウェイポイント到達判定（平面距離 0.2m 以内）、待機タイマー、到着時モーションの再生。
- プレイヤー接近追従時、指定の停止距離（例: 1.8m）手前で立ち止まり、プレイヤーの方を向く自然な歩み寄り挙動。
- プレイヤーが離れた場合やテリトリー境界（初期位置から 15m）を超過した際に、初期配置位置へ自律歩行で戻る安全帰還（Return to Home）機能。

### 3. Scene Edit UI「Movement」タブ (`UI/SceneEditWindow.cs`)
- 上部タブバーに第4のタブ「**Movement**」を新設。
- 移動モード選択（None / Patrol / Follow Player / Patrol + Follow）。
- 移動速度スライダー（0.5〜10.0m/s）およびワンクリックプリセットボタン（歩き 2.0 / 駆け足 4.0 / 走り 6.0）。
- 「📍 自キャラ位置を追加」「📍 アクター位置を追加」ボタンで、現在立っている場所をワンクリックでウェイポイントとしてルート登録。
- ウェイポイント一覧（並び替え ▲▼、待機秒数ドラッグ編集、個別削除 ✕、全消去）。
- プレイヤー追従・テリトリー境界設定（Trigger Dist, Stop Dist, Territory Limit, Return to Home）。

### 4. 3D 空間上での巡回ルートライン・ピン描画 (`UI/GizmoRenderer.cs`)
- 登録されたウェイポイント間を黄色いラインで結び、各地点に番号ピン（#1, #2...）をオーバーレイ描画。
- ホーム位置から最初のウェイポイントへの接続線（水色）および、循環モード（Loop）時の最終地点から開始地点への接続線を表示。

## 動作確認手順

1. **プラグインの更新**:
   - Dalamud プラグイン一覧より最新版（`v0.1.82.0`）にアップデートします。
2. **シーン編集ウィンドウの確認**:
   - `/cs` コマンドでメインウィンドウを開き、「Scene」タブから「Edit Scene」を開きます。
   - 上部のタブに「**Movement**」が追加されていることを確認します。
3. **ウェイポイント巡回テスト**:
   - リストからキャラクター（例: MCDF Ruma やラプトルなど）を選択し、「Movement」タブを開きます。
   - `Movement Mode` を「`Patrol (巡回)`」に切り替えます。
   - 自キャラを歩かせて、「📍 自キャラ位置を追加」ボタンを 2〜3 箇所で押します。
   - ゲーム画面上に黄色いラインと番号ピン（#1, #2, #3）が表示されることを確認します。
   - キャラクターが設定した地点を順番に歩いて巡回することを確認します。
4. **プレイヤー接近追従テスト**:
   - `Movement Mode` を「`Follow Player`」または「`Patrol + Follow`」に切り替えます。
   - 自キャラでアクターに近づくと、アクターが自キャラに向かって歩み寄り、1.8m 手前で立ち止まることを確認します。
   - 自キャラで遠くへ逃げると、アクターが元のホーム位置へ自律的に歩いて戻ることを確認します。
